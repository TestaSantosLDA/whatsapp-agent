# WA-021: Automatic PR review from Claude Code

| Status    | Milestone | Depends on | PR  |
| --------- | --------- | ---------- | --- |
| in review | Tooling   |            |     |

## Why

Every PR should get a second pair of eyes before merge. A reviewer that starts from a clean context catches what the author session misses, and doing it automatically means nobody has to remember to ask.

## Scope

- A project skill `.claude/skills/pr-review/SKILL.md` that tells a reviewer how to fetch a PR, check it against its ticket and `docs/architecture.md`, run the repo checks, verify findings and post the review.
- A PostToolUse hook `.claude/hooks/pr-created.sh`, registered in `.claude/settings.json`, that detects a PR created by `mcp__github__create_pull_request` or `gh pr create` and tells the main agent to start a fresh background reviewer subagent with that skill.
- A short README section.

## Acceptance criteria

- [ ] Creating a PR from a Claude Code session (CLI, desktop, Claude app / cloud) with the GitHub MCP tool or `gh pr create` triggers a background reviewer subagent.
- [ ] The reviewer uses the session's own Claude subscription: no `ANTHROPIC_API_KEY`, no GitHub Action.
- [ ] The review is posted on the PR as inline comments where useful plus one summary comment with `## Summary`, `## Must fix`, `## Recommended`, `## Checks run` ("None" for empty sections).
- [ ] Every comment ends with the `_Generated by [Claude Code](https://claude.ai/code)_` footer.
- [ ] The reviewer never approves, requests changes as a blocking state, merges or pushes.
- [ ] The hook never fails a tool call (always exits 0) and stays silent for unrelated tool calls.

## Out of scope

- PRs opened by hand on GitHub or from other tools: the hook only runs inside Claude Code sessions.
- A GitHub Action / API-key based reviewer.
- Blocking merges on the review result.

## Notes

- Only covers PRs opened from Claude Code sessions, not PRs opened by hand on GitHub.
- A GitHub Action with an API key (e.g. `anthropics/claude-code-action`) can replace or complement this later to cover every PR.
- Hook output uses `hookSpecificOutput.additionalContext`, which Claude Code injects next to the tool result.
